# Event App

Mobile application for organizing events.

## Features

- Create events
- Manage participants
## Setup Instructions

1. Clone the repository
2. Open src/index.html in a browser
## Project Structure

- src/index.html - main page of the app
- docs/readme.md - project documentation

## Git Workflow in VS Code

- Branches: main, feature-style, feature-docs
- Changes are committed via Source Control (+ and Commit)
- Branches are merged via Git: Merge, conflicts are resolved in the editor
- Fetch is used before Pull to check remote changes

Alternative path: revert to restore previous state.
